## 📌 Project Overview

**Nassau Candy Data Analysis** is an end-to-end data analytics and business intelligence project developed using Python and Streamlit.

The project analyzes Nassau Candy distributor data to understand **sales, costs, gross profit, profit margins, products, divisions, factories, and business trends**.

The analysis transforms raw business data into meaningful insights through data cleaning, exploratory data analysis, profitability analysis, trend analysis, Pareto analysis, margin and risk analysis, factory analysis, and business recommendations.

An interactive **Streamlit dashboard** brings the complete analysis together through KPIs, charts, filters, analytical tables, insights, and recommendations.

### 🔄 Analytics Workflow

**Raw Data → Data Cleaning → EDA → Business Analysis → Visualization → Insights → Recommendations → Interactive Dashboard**

## 3. 💰 Product Profitability Analysis

Product profitability is analyzed using important financial metrics:

- Sales
- Cost
- Gross Profit
- Gross Profit Margin

The analysis identifies:

- High-profit products
- Low-profit products
- High-margin products
- Low-margin products
- Products requiring attention

### Gross Profit

```text
Gross Profit = Sales - Cost
```

### Gross Profit Margin

```text
Gross Profit Margin = (Gross Profit / Sales) × 100
```

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/GaneshKumarSeepana/Nassau-Candy-Data-Analysis.git
```

## 2. Navigate to the Project Directory

```bash
cd Nassau-Candy-Data-Analysis
```

## 3. Create a Virtual Environment

### Windows

```bash
python -m venv .venv
```

Activate the environment:

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv .venv
```

Activate the environment:

```bash
source .venv/bin/activate
```

## 4. Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Dashboard Locally

From the project root directory:

```bash
streamlit run dashboard/app.py
```

After running the command, Streamlit will provide a local URL:

```text
http://localhost:8501
```

Open this URL in your browser to access the dashboard.
